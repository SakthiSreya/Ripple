# Ripple

A developer tool that analyzes code dependencies and predicts the potential impact of code changes.

## Problem

Understanding how a change in one file affects other parts of a codebase can be difficult, especially in large projects.

## Goal

Ripple aims to help developers visualize code dependencies and identify potentially affected files before making changes.

## Planned Features

- GitHub repository integration
- Code dependency analysis
- Change impact analysis
- Interactive dependency visualization

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB

## Status

Currently in development. This project is being built while learning the MERN stack.
